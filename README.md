# Telegram Auto Send Bot
ロボットの送電からのメッセージを、お客様はご自身のアカウントで柔軟に設定のコードは、個人管理なので、参加)

## 1.📁 インストールガイド
 -ボットファイルをダウンロードし、あなたのために便利な場所にアーカイブを解凍します。
 -コード内のパラメータを独自のものに変更します
 -次に、ファイルまたはコンソールからロボットを起動します。（また、Pythonとロボットが動作するために必要なライブラリがインストールされていることを確認してください。)
 -次に、Telegram自体でロボットのログインを確認してセッションを作成します。
 -今すぐ希望のチャットに行くと、ロボットはそれ自体でメッセージの送信を開始します。!!!

## 2.💸 空室状況
 - ロボットは個人的な使用のために完全に無料です。:3
